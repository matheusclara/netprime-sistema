COMO RODAR COM DOCKER COMPOSE

1. Entrar na pasta do sistema:

   cd /home/nocprime/netprime_sistema_unico_real

2. Parar o servico antigo, se estiver usando systemd/gunicorn fora do Docker:

   sudo systemctl stop netprime

3. Subir com Docker Compose:

   docker-compose up -d --build

4. Conferir se subiu:

   docker-compose ps
   docker-compose logs -f --tail=80

5. Acessar:

   http://primevendas.netprimegroup.com.br:8088/

IMPORTANTE

- Os dados ficam fora do container nestas pastas:
  data
  uploads
  backups

- Nao apague essas pastas. Elas guardam usuarios, historico, contratos enviados e backups.

- O Docker usa a porta interna 5000 somente no localhost da VM.
  O Nginx continua atendendo o publico na porta 8088 e encaminhando para 127.0.0.1:5000.

- Para atualizar o sistema depois:

  git pull
  docker-compose up -d --build
